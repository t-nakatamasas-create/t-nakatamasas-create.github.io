# 同時通訳字幕アプリの紹介

## 1．このアプリについて

このアプリは、本校である**大阪府立城東工科高等学校および大阪府立東大阪みらい工科高等学校の国際交流会**で、言語の違いによるコミュニケーションの壁を少しでも減らすことを目的に開発しました。

日本語や韓国語など、異なる言語を話す参加者が、相手の発言内容を字幕で確認しながら交流できるようにするアプリです。音声を認識して翻訳し、画面に字幕として表示することで、国際交流をより円滑に進めることを目指しています。

## 2．アプリの仕様

- **音声認識：** マイクで取り込んだ発言を文字に変換します。
- **翻訳：** 認識した文章を指定した言語に翻訳します。
- **字幕表示：** 翻訳結果を画面上段、音声認識した原文を画面下段に表示します。
- **言語切り替え：** 日本語から韓国語、韓国語から日本語など、用途に応じて翻訳する言語を切り替えます。
- **翻訳APIの切り替え：** 対応する翻訳サービスを選択できるようにし、利用環境に応じた運用を目指します。
- **音声読み上げ：** 翻訳結果を音声で読み上げる機能を備えています。
- **字幕履歴・出力：** 過去の字幕を確認し、テキストファイルやCSVファイルとして出力できます。
- **表示設定：** 文字サイズの変更や全画面表示に対応し、会場のスクリーンなどでも利用しやすい構成としています。

※実際の動作や利用可能な言語・翻訳サービスは、使用するブラウザ、APIの設定、通信環境などによって異なります。

## 3．今後について

今後は、国際交流会での実際の使用を通じて、翻訳の正確性、字幕表示の速さ、操作性などを検証し、改善を進めていきます。

また、交流相手の学校や使用する言語に応じた設定を充実させるとともに、翻訳サービスの選択肢を増やし、安定して利用できる環境を整えていく予定です。

将来的には、学校間の交流だけでなく、授業や学校行事、海外の学校とのオンライン交流など、さまざまな場面で活用できるアプリを目指します。

このアプリを通じて、生徒たちが言語の違いを越えて互いの文化や考え方を理解し、積極的に交流できる機会を広げていきたいと考えています。
